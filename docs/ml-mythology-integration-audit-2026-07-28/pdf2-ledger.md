## Provenance rule used

The PDF is a conversation export. Turn order establishes source type.

- **User-authored statement** means text directly entered by the user in the exported exchange.
- **Assistant synthesis** means text generated by the assistant, including retrospective claims about what the user supposedly established.
- **Pasted quotation** means a quotation reproduced inside the export whose deeper origin is not established by this PDF alone.
- **External citation** means an externally authored work is invoked as evidence. A bare title or thinker-name is treated as a citation lead, not verified evidence.
