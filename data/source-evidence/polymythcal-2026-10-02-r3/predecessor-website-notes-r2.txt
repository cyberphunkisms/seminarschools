POLYMYTHCAL WEBSITE FIXES — 2 OCTOBER 2026
Revision 2, following the delivered-package audit.

This ZIP contains the complete editable website source and its built public/
folder. Polymythcal shares this website with other Seminar Schools sections,
which are retained. It is a website handoff, not the full Polymyth project or
research archive. It does not require the seven archive transport ZIPs to
build the website. The original full project archive is preserved separately.

CHANGES
- Explicit unconfirmed "projected source watch" records now enter the undated
  watchlist even when an old importer assigned an exact placeholder timestamp.
- The first repair moved 26 such records out of the dated calendar and ICS
  exports. This follow-up moves another 53 projected deadlines, annual windows
  and placeholder dates to the watchlist, including 46 upcoming records.
  No source-confirmed deadline is inferred from an annual pattern. Their stable detail
  pages and original canonical records remain. All 2,086 record IDs are retained:
  1,871 chronology records and 215 watchlist records.
- The first repair made 18 targeted primary-source reviews correcting dates,
  venues, titles, status or
  destinations. National Humanities Center's deadline was October 1, not October
  2. Getty Center's 2027–28 Scholars Program is paused. Hellhound Trail also plays
  October 3. Melissa Auf der Maur and Sunday Best now use their verified public
  opening dates, separately from early member access. Four Kingston productions,
  seven TSO listings, four AGO exhibitions and the Scholastic cycle are reviewed.
- In the first repair, exact external destinations rose from 851 to 868. Unverified broad links are
  not promoted to event links. Unknown cities fall from 402 to 389.
- Source-reviewed corrections survive normal rebuilds. The dated ledger retains
  the complete predecessor records and source URLs. No historical source-check
  timestamps outside those reviewed records are advanced by this repair.
- The Scholastic regional-deadline listing now gives the current $15 individual
  and $40 portfolio fees with waivers. The related cycle-opening listing carries
  the same information. The regional deadline remains unknown and undated.
  This brings the cumulative targeted source-review set to 19 distinct records.
- National Humanities Center and Getty Scholar opportunities use the funding
  filter. Existing fellowship metadata also outranks the legacy generic CFP type.
- English and French listing cards expose lifecycle states, including closed
  registration and cancelled or paused programs. Getty's date panel displays its
  paused/cancelled state instead of saying it awaits a date.
- Exact external destinations now total 869; 1,217 remain unresolved.
- Long watchlist date/status labels fit within their column without overlapping
  listing titles.
- The scroll geometry refreshes its section measurements at the next paint after
  asynchronous calendar results and their action buttons finish rendering. The Writing Kids desktop convergence
  failure exposed stale measurements from before the listing load. Hidden panels
  and fallback headings no longer create phantom outline positions. The browser
  expectation was corrected to exclude those non-rendered headings as well; its
  timeout and numerical tolerance remain unchanged.
- The Discovery browser asset version advances to 20261002-discovery-v5 so
  cached scripts from the earlier release cannot hide these interface repairs.

AUDIT CORRECTION
The audit's claim that the main calendar lacked initial listings without
JavaScript was incorrect. It already contained 24 static listing links.
That finding and the proposed reopening of issue 32 are withdrawn. Browser
checks now verify the existing fallback and its detail links on the main,
research and monitoring pages in both languages with JavaScript disabled.

BUILD
Use the versions pinned by this project's runtime files and package.json.
  npm ci
  python3 -m pip install --require-hashes -r requirements-audit.lock
  SITE_BUILD_DATE=2026-10-02 npm run build
For a later normal build, use that day's SITE_BUILD_DATE. A build date is not
an assertion that all source records were checked that day.

Repository handoff: inspect `git status`, create a review branch with
`git switch -c polymythcal-fixes-2026-10-02`, apply this website tree to the
website repository root, and review `git diff --stat` and `git diff` before any
commit or deployment. Remove obsolete ICS paths listed in the change receipt;
overlaying an extracted ZIP alone does not remove retired files in an existing
checkout. Keep private source data out of hosting: only public/ is the publish
folder. No push or deployment is implied by these instructions.
