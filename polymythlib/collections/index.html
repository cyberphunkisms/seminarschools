How curation works

Transparent inclusion, plural usefulness.

Collection membership is a Polymyth editorial choice. It is recorded separately from the book’s historical claims and from current status verification.

Rule visible

Every collection explains the question or facet that gathers its records. The versioned collection file publishes each rule, anchor record, count, and member ID.

Multiple homes

One project can be a repository, preservation project, scholarly commons, and network member at once.

Descriptive signals

Concrete features and evidence coverage remain visible across projects serving different purposes.
