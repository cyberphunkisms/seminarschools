## Provenance discipline

- Statements identified as Detienne's argument, example, qualification, or citation lineage are **source-direct reports**. Reporting them does not independently verify every historical assertion.
- Sections labelled analysis, inference, tension, synthesis, or provisional Polymyth application remain **analyst inferences or proposals**.
- Project rulings live in the current project owners and in the audited master note. They are never inferred from the repetition of an assistant proposal.
- Noncoverage states that this book does not establish a subject. It is not opposition. Validation debt applies only where a claim is actually advanced and still needs verification.
- Page references are printed book pages unless a PDF page is explicitly given.

## Current interpretive controls

1. Detienne is a point in favor of the project's **always-already claim**. This is a user ruling about the source/project relation. It is not attributed to Detienne in the project's vocabulary.
2. The genealogy concern receives the exact status **Non-opposition-as-presented**. The book's failure to supply a modern therapeutic-boundary genealogy does not oppose a claim that did not depend on that genealogy.
3. “Polycognate is a complex axiom that always survives” remains the user's current ruling. Particular pairings can be corrected without converting their failure into defeat of the axiom.
4. Proposed priorities, worksheet fields, and Detienne-derived project applications remain unratified unless the user adopts them.
5. The book supports a critique of credentialed jurisdiction while preserving the necessity of real expertise. It supplies no blanket anti-academic or anti-expertise conclusion.
